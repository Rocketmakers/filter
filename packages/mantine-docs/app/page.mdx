# filter-builder · Mantine

A shadcn-style filter builder ported to **Mantine v8** + **SCSS modules**.
Every colour and spacing reads from CSS custom properties defined in
`src/theme/brand.scss`, so dropping the component into a Mantine app
inherits your existing theme.

## Example

The demo below is the same component you get from
[`pnpm dlx @rocketmakers/filter mantine`](./install) — six data types
(text, number, boolean, select, date, dateTime) over a mock employee
dataset, with URL-bound state.
