# filter-builder

A shadcn-style filter builder, ported across three styling stacks. Pick a
variant from the sidebar to read its Intro, Install, and Integrations
guides.

- **[Mantine](./mantine)** — Mantine v8 + SCSS modules.
- **[Style-X](./stylex)** — Style-X atomic styles.
- **[Tailwind (shadcn)](./tailwind)** — Tailwind CSS + shadcn primitives.
